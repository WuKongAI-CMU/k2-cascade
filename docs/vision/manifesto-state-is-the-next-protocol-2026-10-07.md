# 状态是下一个协议：让任何家族、任何尺寸的模型读懂另一个模型

*2026-10-07。【已证明】= `docs/paper/main.tex` v5 里带对照的测量；【赌注】= 带日期和"错了算什么"的预测。文末有总账。*

模型之间今天用文本交接，不是因为文本合适，而是因为我们还没造出别的东西。我押它会被换掉：十年内，一群不同家族、不同尺寸的模型之间传的是状态，不是转写稿。

## 一、文本是模型之间的 HTTP/1.0

HTTP/1.0 每次请求重新握手、把一切序列化成人类可读的头部；文本交接也一样：接收者每次重新 prefill 整段上下文，发送者把中间表示压成 token，再由接收者猜回去。它能用，靠的是惯性：模型被训练来读它，人能审计它，日志能存它——没有一条是两个模型之间该用它的理由。

今天坏在三处（`goal/GOAL.md` 北极星第二句）：文本带不走已算过的计算、带不走信念的形状（哪些候选、各占多少）、带不走不是词的中间表示。前两条我们量过。

【已证明】置信词作为标签直接对发送者的语义熵打分，AUROC .955 / .942 / 1.000（clean / contradicted / removed 三种段落）；同一个词经 7B 接收者读完，接收者首 token 熵的 AUROC 是 .552 / .542 / .592，和什么都不给它（.532 / .479 / .603）一个水平。**标签带着信号到达，读者把它扔了。** 这是一个 base 模型在一种补全提示下的性质，没做指令微调接收者的消融；但"文本洗白置信度"（置信词被接收者当没看见）罪在读者，不在信道容量。

领域的审计指向同一处：2608.04893 发现中继 KV cache 的收益多数是接收者自己的计算（MedQA：+14.7 分里只有 +0.4 是内容特异的）。管子快，不等于东西过去了。

## 二、状态通道修了什么

通道的具体物：发送者每层每头的 KV cache，经一个 151M 参数的逐头投影器（岭回归底座加门控残差，只在 FineWeb-Edu 续写损失上训 1,500 步），插进接收者的 cache 前缀；接收者只读问题。

【已证明】8 名字绑定测试（n = 1000，机会 12.5%）：投影 cache 63.0%；递另一集的 cache 4.6%，且 63.7% 的时候答成另一集的值；用无关文本训出来的投影器 23.4%（岭底座 21.7%，所以它不算完全无内容）。**接收者不是忽略缓存，它在读缓存——递错了它就答错。**

【已证明】SQuAD：只给问题 16.6 F1，读段落 54.7，读发送者的投影 cache 53.0；错段落的 cache 13.8。HotpotQA 两端各持一段：自己那段 30.1，加发送者那段的 cache 39.9 ± 2.1，加文本 45.8，deranged cache 29.9–32.1。

【已证明】发送者 3.7B 隐状态上的线性探针预测它自己会答错：AUROC .749，高于它自己的语义熵 .689。

## 三、一种协议，一群异构模型

K2 Horizon 3.7B → 7B 只是第一个能用的配对，不是框架。

【已证明】Qwen3-4B → K2-7B，词表和预训练都不同、KV 几何相同：同一配方三个种子 71.7 ± 4.5%，deranged ≤ 4.7%，SQuAD 48.3 ± 3.5 对文本 54.7；只用线性映射 18.0%——跨族时线性什么都不是。反向 7B → 3.7B 63.3%。

【已证明】K2-0.9B → 7B：词表、层数、头维度（64）同时不同，同一配方 17.0%（deranged 14.0%），F1 24.2。哪一处差异致命没测；别处存在跨头映射，所以失败的是这个参数化，不是这个配对。

读法：**几何能复制的时候，复制是捷径；几何不能复制的时候，消息空间得学出来。** 2608.03893 的闭式映射 Qwen3 14B→32B 保留 97.6%、Ministral 8B→14B 只剩 41.6%，同一个教训。领域正从两头逼近：机器人内部已有状态交接（Helix、GR00T）；Interlat、StateBridge、C2C、Dense Latent Communication 在做跨模型隐态接口；TypeSafe 的 Jev 干脆不出文本，只出带校准概率的类型化决策。差的是任何家族、任何尺寸都能接上的那一个协议。

【赌注】到 2027-06-30，一个"发送者编码器 → k 个消息槽 → 接收者解码器"的学习消息空间（槽 {16, 64, 256}，int4 实打包计字节）让 0.9B → 7B 在绑定测试上 deranged 臂回到机会水平、投影臂过 50%。错了算什么：三个种子都没过 40%，"学出来的消息空间能跨几何"在这个尺度上就不成立。

## 四、账单先摆出来

【已证明】cache 144 KB/token，512 token 前缀 72 MiB，对比约 1 KB 文本。GPU 内：接收者重读 48 ms，投影 24 ms。走 1 Gbps 链路：约 604 ms 传输，换省下的 24 ms。int4 伪量化到 36 KB/token 保住 75.0% / 51.6 F1；砍层不行（只传 18–35 层：28.7%，16.1 F1）。

【已证明】SQuAD 上 7B 读段落只比 3.7B 高 3.5 F1（55.7 对 52.2），cache 交接停在 51.8，什么触发器都不划算。预注册的"cache 臂 AUROC ≥ .70"没达到（.585 / .605 / .624；文本 .597 / .615 / .671）：内容过去了，不确定性只过去一部分。

**今天这条通道是一台测量仪器，不是一个部署**——仪器就是那个 151M 投影器加绑定测试的对照臂。thesis 价格表押"≤ 1 MB 的学习编解码会死"；我押上一节那条。到期对账。

## 五、当每个模型都能读另一个模型的状态

以下全是赌注。

【赌注】自改进系统不是一个模型变强，是一群模型互递状态、从返回里学。**知道自己不行（探针 .749）、把状态递出去（通道）、从返回里学（未做）——这是那个循环的前三步。** 第三步的杀线已写：返回状态教发送者不比返回文本多（三个种子内 (b) − (a) ≤ 0），就只是蒸馏。

【赌注】状态一旦可交易就有价（字节、毫秒、每美元准确率）、有骗（自信的错状态）、要审计。接收者侧探测器分辨真假 cache 的 AUROC 过不了 .7，通道就过不了信任边界。

【赌注】预测 2：到 2028-12-31，某前沿实验室或前五推理商在自家家族内上线带日志或文本回放的 KV 交接。预测 11：到 2027-12-31，同族投影器在接收者更新后不重拟合、保留率掉超过 10 分。预测 3：到 2030-12-31，没有生产系统跨厂商传隐状态。预测 3 若成真，这里的"群体"是一个所有者的模型群——我认，并照样写。

## 六、给造 agent 系统的人

你不必等通道。现在就能加的一行：**凡是报 verbal-confidence 基线的地方，把标签直接打分的 AUROC 和接收者 AUROC 并排印出来。** 第二行：凡是报隐态收益的地方，加一个 deranged 对照（递另一条样本的状态），否则分不清通道和软提示。两行都不花 GPU。

然后再谈协议。
