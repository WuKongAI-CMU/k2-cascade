# 状态是商品：给模型间交易写一套清算规则

*2026-10-07。写给 Peter 和所有在搭 agent 系统的人。数字只来自 docs/paper/main.tex、docs/thesis/thesis.tex、goal/GOAL.md 和 docs/agent-communication-futures-2026-09-21.md；【已证明】指有对照组的测量，【赌注】指有日期或淘汰条件、尚无证据的判断。K2 Horizon 只是第一批实验用的模型，不是这篇文章的边界。*

我们打赌：十年内，模型之间交易的主要商品不是文本，而是算过的状态；而让这个市场能清算的三件东西，我们已经动手做了两件半。

## 一、价签已经贴出

2026 年 9 月，TypeSafe AI 发布 Jev：一个不输出文本、直接返回带校准概率的类型化决策的模型，定价每百万 token 0.042 美元（厂商自报，"193.6x faster"也是自报，原文附了"0.114s vs 8.566s"两边的数）。Jev 卖的是决策，一个数加一个概率；我们说的商品更原始：状态，具体是 KV cache，一个模型读完一段文字后每一层注意力留下的键值张量。决策是状态的最后一行，状态是决策的全部账本。

**价签贴出来那天市场就开张了，商品是什么可以晚一点再吵。**

## 二、成本：这件货太重

【已证明】一个 512 token 的段落，映射后的 KV cache 是 144 KB/token、共 72 MiB；同一段文字约 1 KB。在 1 Gbps 链路上传它要约 604 ms，而它替接收方省下的只有 24 ms 重算（接收方自己重读 512 token 要 48 ms，映射器要 24 ms）。int4 量化压到 36 KB/token，SQuAD F1 从 53.0 到 51.6，几乎白送；再砍层、砍头、降秩，内容跟着没了（只传第 18–35 层：16.1 F1）。今天的结论很冷：同一块 GPU 内，状态在时间上清算；一过网线，文本赢。

【赌注】淘汰条件已写好：若每条消息 ≤1 MB 内没有任何学到的编码器能把 SQuAD F1 保在文本 5 分之内、且错配对照接近随机，这条信道就永远只是测量仪器。作者押它在 1 MB 处死掉。

**运费是节省算力的二十五倍时，没有市场，只有仓库。**

## 三、价值：买家确实读到了货

市场需要一个度量衡局，这里指的是对照组：错配缓存（另一题的 cache）、零缓存、矩匹配随机缓存、只给问题。【已证明】8 名字绑定测试上，训练后的映射器 63.0%，随机 12.5%，错配缓存 4.6%，而接收方 63.7% 的时候照着错配缓存里的错值回答——它不是在忽略货，是在读货。真实段落：SQuAD F1 53.0，文本 54.7，只看问题 16.6；错题的缓存 13.8。HotpotQA 两方各持一段：39.9 ± 2.1，文本 45.8，不传 30.1。跨家族 Qwen3-4B → K2-7B：71.7 ± 4.5，和同家族一样；K2-0.9B → 7B：17.0（错配 14.0），这一对失败。2608.04893 的审计提醒过：MedQA 上 +14.7 分里只有 +0.4 是内容特异的。我们每个数字旁边都站着它的对照。

【赌注】几何不是边界。0.9B 对失败的是这一种参数化，不是这一对模型；学到的消息空间（编码器把 cache 压进 k 个槽，解码器展开到接收方每一层）是绕过头维度、词表、层数差异的路。带价目录要给 C2C、StateBridge、Interlat、闭式 KV 映射同样四列：字节/token、延迟对重算、带错配对照的绑定准确率、审计 AUROC。淘汰条件：几何与词表特征预测不了传输率，"传输是三元组的性质"就撤。

**买家读到货，是这个市场成立的第一张凭证；对照组是开凭证的人。**

## 四、欺诈：自信的错误状态

这个市场最便宜的欺诈不是撒谎，是把犹豫留在家里。2606.20662 叫它"置信度洗白"。【已证明】我们测了四种交接：把置信度词当标签直接打分，对发送方语义熵的 AUROC 是 .955 / .942 / 1.000（三种段落变体）；接收方读了这个词之后，.552 / .542 / .592；什么都不给，.532 / .479 / .603。信号在消息里，读的人扔了。洗白的不是文本，是这个读者。映射缓存 .585 / .605 / .624，预注册的 ≥.70 没达到：内容过去了，不确定性只过去一部分。同题换段落（干净 → 删掉答案句），接收方熵变与发送方熵变的 Spearman：缓存 .280，文本 .322，词 .146，另一题的缓存 .004。

欺诈本身没有测过。测到的只是前提：接收方读什么信什么（63.7% 跟着错值走）。【赌注】接收方侧一个线性探针区分真映射缓存与篡改缓存，AUROC 要过 .7，且要赢过"把同一个数当文本发过去"的审计；再训练一个被奖励"显得自信"的发送方来攻它。探针 ≤.7，信道就跨不了信任边界。

**洗白置信度的不是信道，是收信的人；审计因此要查两处账：先查消息，再查读者。**

## 五、清算机制：三件原语

成本、价值、欺诈，对应价格、信誉、审计。我们的三件东西正好一一对应。

信道，即那个 ridge 加 151M 参数残差的逐头映射器，把"价值"变成可测量：买家读没读到，绑定测试和错配对照说了算。随行的不确定性，即发送方隐状态上的失败探针加"先打分消息、再打分读者"的两级审计：【已证明】探针在 600 道 SQuAD 上 AUROC .749（语义熵 .689），127 步 agent 轨迹上 .876 [.813, .944]（元数据 .704）。知道自己不行，是卖家挂牌的前提。每美元准确率，即跑之前写死的价目表：【已证明】SQuAD 上一次文本交接买到 3.5 F1，花 48 ms（45 → 93 ms/题），缓存交接买到零。3.5 F1 值不值 48 ms 是价格判断，不是测量；没有价目表，这个判断没人能做。

信誉没测。信誉要求卖家的可靠性会变，而仓库里三个映射器检查点是静止的。【赌注】预测 11：接收方做一次后训练更新后，不重拟合的同家族映射器掉 >10 分留存率，期限 2027-12-31；这是让卖家可靠性动起来的最便宜办法，信誉和漂移因此合成一个实验。

**价格、信誉、审计：市场不需要相信卖家，只需要能查账。**

## 六、反方：电线在权重处分叉

仓库里有一份和北极星唱反调的文件：稠密潜在信道只在共享权重的边界内运行，跨组织的一律是签名、重写成标准格式的文本；拦住它的不是工程，是法律——留存记录、责任、隐私、反垄断都假设有人能读那条消息。十五条带日期的预测里三条压在我们身上：到 2030-12-31 没有生产系统在两家厂商的模型之间传潜在状态（预测 3）；到 2028-12-31 有保险条款把未留痕的 agent 交接单列除外（预测 13）；预测 11 如上。Jev 是旁证：第一张价签卖的恰是跨边界可读的类型化决策，不是状态。

如果反方赢，我们研究的人口就是一个所有者名下的模型群，不是 agent 经济。这是站得住的论文，不是我们打的赌。分歧没有解决，只是排了期：三条预测各在到期日记分。

**如果法律赢了，市场照样存在，只是边界画在权重上，不画在公司之间。**

## 七、什么会杀死整个赌注

四件事，任一件缩小论文：消息压不到 1 MB 附近还保内容；一个指令微调的接收方把"confidence: low"读得和缓存一样好，那不确定性就是重算的，不是传过去的；返回的状态教发送方的不比返回的文本多，那"从回来的东西里学"就是蒸馏的别名；这个尺度上找不到差距够付运费的任务——SQuAD 的 3.5 F1 已经杀过一次里程碑 4。
