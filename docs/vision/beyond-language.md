# 语言之外

### 当模型开始交换彼此的心智

今天两个 AI 合作，做法和两个人隔着墙递纸条差不多。一个模型读完材料，把想到的东西写成一段话，另一个模型再从头读这段话。前一个模型读的时候权衡过什么、犹豫过什么、差一点选了哪个答案，全都留在它自己那里。纸条上只剩结论。

我们早就习惯了这件事，因为人和人之间只能这样。可模型不是人。它们的"想法"本来就是一堆可以拷贝的数字，没有理由非得先翻译成人话，再让对方翻译回去。

1986 年，明斯基在《心智社会》里说，一个心智本身就是一群小 agent 组成的社会。四十年后，我们真的在造这样的社会了：路由、级联、多 agent，小模型打下手，大模型拍板。只是这个社会里的成员，到现在还只会说我们的语言。

---

香农在 1948 年把通信问题定义得很干净：在一端复现另一端选出的消息。我们想知道，如果这条消息不是文字，而是一个模型读完材料后脑子里的状态，另一端能复现出什么。

我们拿了两个大小不同的模型。小的那个读一段材料，我们把它读完后留在注意力里的记忆翻译成大模型能读的格式，直接放进大模型的脑子里。大模型自己从没看过那段材料。

它答出来了。给八个生造的名字各配一种颜色，只让小模型看，然后问大模型"Vela 是什么颜色"。瞎猜是八分之一，它答对六成多。更有意思的是反过来：把另一道题的记忆塞给它，它多半会照着那份错的记忆，答出错的颜色。它不是在猜，它在读。

真实的文章也一样。读别人的记忆和自己读原文，答题分数几乎打平。换一个完全不同家族的模型当发送方，也通。

---

第二件事更让我们在意。

一个模型交出答案时，真正值钱的往往不是答案，是它有多确定。我们先试着用文字把这份确定交过去，在答案后面附一句"我的把握：低"。接收的模型几乎当没看见，它的犹豫和发送方的犹豫对不上，跟什么都没收到时差不多。

换成交出状态，事情就变了。同一道题，我们只把小模型读的材料里答案那一句悄悄删掉，小模型开始犹豫；接收方读着它的记忆，也跟着犹豫起来。换成别的题的记忆，问题一字不变，两边的犹豫就再也对不上了。这个效应现在还不大，相关系数从零走到 0.28，但它不是零。

文字把结论递了过去，状态把犹豫也带了过去。

---

为什么我们这么在乎犹豫？

1945 年，哈耶克写了《知识在社会中的运用》。他问的问题看起来是经济学的：没有任何一个人掌握整个社会的知识，那散落在千万人手里的知识怎么协调起来？他的答案是价格。价格是一台传递知识的机器，它把每个人各自知道的东西，压成一个所有人都看得懂的数字。

AI 正在走到同一个问题面前。接下来会有成千上万个 agent 互相分包工作：一个看懂了合同，一个算完了账，一个刚在某个网页上撞了墙。它们之间流动的，迟早不只是任务，还有知识、判断和把握。这样的经济需要它自己的那台机器。我们赌这台机器传的会是状态。

一旦状态能交出去，它就成了商品：有成本，有价值，也会有假货。最便宜的造假用不着撒谎，递过去一份看起来很有把握、其实错了的状态就够了。所以交接时连同"我有多确定"一起交，是这个经济最起码的诚信。

再往前一步。一个知道自己哪里不行的模型（我们训练过这样的探针，它在开口之前就能大致预测自己会不会答错），把状态交给更强的模型，拿回结果，从里面学到东西。这个循环一旦转起来，一群模型就会比其中任何一个都强。我们相信自我改进的系统会长这个样子：不是一个越来越大的模型，而是一个越来越会互相交接的社会。

---

这条路离走通还远。今天一页文字的记忆有 72 MB，在同一块显卡里交接比重读快一倍，一过网线就比发文字慢得多。我们押的下一步，是学会把一个心智的状态压到几 KB，同时留住它读到的东西和它的犹豫。做不到，这只是一台精巧的测量仪器。做到了，模型之间就有了自己的语言。

维特根斯坦说，我的语言的界限，就是我的世界的界限。对人来说，这是一句关于局限的话。对模型来说，语言从来不是它们的边界，是我们替它们划的。
