# 状态交接：先给消息打分，再给读者打分

*2026-10-08。【已证明】= 有对照组的测量，数字出自 `docs/paper/main.tex`、`docs/thesis/thesis.tex` 或 `analysis/cloud/` 下的 json；【赌注】= 带日期、写明怎样算输的预测。*

一份映射后的 KV cache，512 token 前缀就是 72 MiB；同样的文字约 1 KB。这里的 KV cache 指模型读完一段文字后每层注意力留下的键值张量，"映射"指一个 151M 参数的逐头投影器把发送方的 cache 改写成接收方能读的形状。在一块 A100 上，投影要 24 ms，接收方重读原文要 48 ms；可一旦走 1 Gbps 网线，这 72 MiB 要传约 604 ms。【已证明】这组数是本文的地基：谁要说"模型之间将来传状态，不传文字"，就得先把这笔账算平。

我们说的就是这句话。【赌注，无日期，出自 `goal/GOAL.md` 北极星】计算的单位正从一个模型变成一群模型，它们之间的协议会从文本换成状态。下面分开写已经量到的和押上的。量到的部分只涉及两个冻结模型、几百道题；押上的每一条都写了到期日。

## 一、账：同一块 GPU 内划算，过了网线就是文本赢

【已证明】省下的是 24 ms 的计算，多付的是约 604 ms 的传输。int4 伪量化把每 token 从 144 KB 压到 36 KB，6 名字绑定测试从 75.3% 到 75.0%，SQuAD F1 从 53.0 到 51.6，链路时间仍要约 151 ms。按层砍不行：只传第 18–35 层，6 名字测试掉到 28.7%，F1 掉到 16.1。

【已证明】SQuAD 上没有交易可做。7B 读原文只比 3.7B 高 3.5 F1（55.7 对 52.2）；把每道题都交出去做文本交接，F1 涨到 55.7，每题多花 48 ms；cache 交接停在 51.8。设计文档写好的淘汰条件（同等成本下状态从没赢过文本）已经触发。

所以今天这条通道（发送方的 cache 经投影器塞进接收方的 cache 前缀）是一台测量仪器，不是一个部署。仪器具体指那个投影器加上绑定测试的几个对照组。thesis 的价目表（`tab:pricesheet`）事先写下的预期是：状态只在同一块 GPU 内能比文本便宜。

## 二、内容：读过的东西能过去，而且接收方真的在读

绑定测试是这样的：给八个生造的名字各配一个颜色（"Noma is amber. Vela is indigo."），只让发送方读，再问接收方某个名字是什么颜色。两个模型都冻结，K2-Horizon-3.7B 发，7B 收。

【已证明】8 名字测试（n = 1000，瞎猜 12.5%）上接收方答对 63.0%。换成另一集的 cache（错配对照），正确率掉到 4.6%，而且 63.7% 的时候它答出的是那一集的颜色。它没有忽略 cache，它在读，递错了就跟着错。用无关文本训练的投影器只有 23.4%，它的线性底座本身是 21.7%，所以这个对照只排除了学出来的那一部分。

【已证明】真实段落上也一样。SQuAD：只给问题 16.6 F1，接收方自己读原文 54.7，读映射 cache 53.0，读错段落的 cache 13.8。HotpotQA 把两段证据拆给两个模型：接收方只用自己那段是 30.1，加上发送方那段的 cache 是 39.9±2.1，加文本是 45.8，换成错配 cache 停在 29.9–32.1。

领域里的审计说明这些对照为什么不能省。2608.04893 发现，中继 cache 在 MedQA 上的 +14.7 分里只有 +0.4 分来自内容，其余是接收方自己多算出来的。cache 接上了、分数涨了，不等于发送方读到的内容过去了。

## 三、没被读的标签：信号在消息里，读的人把它扔了

一个答案只是一个字符串；发送方在那一刻其实握着一个分布，几个备选各占几成。文本能不能把这个形状交过去？Shi 等人（2606.20662）主张不能，把这种损失叫作 confidence laundering，并把它归到文本这条信道上。

我们先给消息打分，再给读者打分。这个做法叫"仅标签审计"：不经过接收方，直接拿消息去预测发送方的不确定性；两者的差叫"读出差"。

【已证明】在 377 道 SQuAD 题、干净段落上：附在答案后的 "confidence: low/medium/high" 这个词，直接当标签预测发送方的语义熵，AUROC .955；7B 接收方读了这个词之后，它自己首 token 熵的 AUROC 只有 .552；什么消息都不给它是 .532。读出差约 .40。这个词不是发送方自己说的，是我们按它的语义熵三分位造出来的，所以 .955 主要来自构造，本身算不上发现。发现是另一头：连按发送方自身不确定性造出来的标签，这个读者也没用上。

我们称之为读者侧洗白，借用 Shi 等人的词，只把位置从信道挪到读者。适用范围要说清：一个 7B 基座接收方，一种补全提示，没有指示它要犹豫。指令微调过的接收方可能把这个差距抹平，我们还没测。

【已证明】cache 这条路：接收方 AUROC .585，读原文 .597；两者之差的区间包含零。预注册的通过线是 ≥ .70，没到。题目固定、只把发送方的段落从干净换成删掉答案句，接收方的熵跟着发送方动：经 cache 的 Spearman .280，经原文 .322，经那个词 .146，经另一题的 cache .004。接收方的把握随 cache 的内容而动，这一点成立；发送方的信念形状本身有没有过来，我们没有实验能单独回答。最省事的解释是证据过去了，接收方据此重算了自己的不确定性。

## 四、跨家族：一对通了，一对没通

K2 Horizon 是第一批数字的来源，不是这件事的边界；但证据目前只有这么多。下面三个数都来自较容易的 6 名字测试（n = 300），不能和上面 8 名字的 63.0% 并排比。

【已证明】同族 3.7B→7B 在 6 名字测试上三个种子是 71.3 / 73.0 / 75.3%，均值 73.2。Qwen3-4B→K2-7B，词表和预训练都不同、KV 几何相同，三个种子均值 71.7%（sd 4.5），和同族相当；只用线性映射是 18.0%。反向 7B→3.7B 是 63.3%。K2-0.9B→7B 失败：17.0%，错配对照 14.0%；它的词表、层数、头维度同时不同，是哪一处致命没测。论文引述的闭式 KV 映射（2608.03893）在同家族对之间保留 44–98%，同样随配对而变。

读法：几何一致时，复制几何是捷径；几何不一致时，消息空间得学出来。"任何家族、任何尺寸"今天不是结论，是下面两条赌注。

【赌注，2027-10-08 前】同一个配方在八对以上的（发送方，接收方，映射）上拟合，用几何和词表特征预测绑定正确率，要好过打乱的基线。做不到，"可迁移性由配对决定"就撤回，这张逐对列出字节、延迟、绑定正确率的配对目录（thesis 的 priced sender catalogue）照常发表，不带这个主张。

【赌注，2027-10-08 前】发送方编码器 → k 个消息槽（16/64/256）→ 接收方解码器，int4 实打包、按线上字节计数。它要在 ≤1 MB 一条消息时把 SQuAD F1 保持在文本 5 分以内，错配臂接近瞎猜；并让 0.9B→7B 的投影臂比错配臂高 10 分以上。thesis 押前一半会失败；前一半失败，通道就一直只是仪器；后一半失败，"任何尺寸"从这份文件里删掉。

## 五、价格、欺诈、审计：一旦能交接，状态就是商品

【赌注，`goal/GOAL.md` 北极星第三句】状态能交接，就有成本（字节、毫秒）、有价值（复用、准确率），也会有欺诈；于是需要价格、信誉和审计。我们手上的三件东西各对一项：通道（那个 151M 投影器）让价值可测；随行的不确定性（失败探针加上面的仅标签审计）让信誉和审计可做；每美元准确率（`tab:pricesheet` 那张价目表）让价格可谈。

价签已经有人贴了。TypeSafe 在 2026 年 9 月发布的 Jev 不返回文字，只返回带校准概率的类型化决策，按每百万输入 token 计费（价格是厂商自报）。被定价的是一个判断加上它有几成把握。决策只是状态的最后一行。【赌注，2027-10-08 前】至少一家厂商对置信度或中间状态单独计价；没有的话，这张价签只是营销。

清算落到一行：同一个问题，买家把"传状态"和"传文本"两份报价按字节、毫秒、F1 填进同一张价目表，单位成本换到的准确率哪边高，就走哪边。今天在网线上，这张表全判给文本。这恰好说明它有用：它会说不。

这个市场里成本最低的欺诈不是撒谎，而是递过去一份笃定但错误的状态。【已证明】欺诈的前提已经在：接收方读什么信什么，递给它另一集的 cache，它 63.7% 的时候照着里面的错值回答。没有对手、没有动机，这还不是欺诈本身。文本的问题出在读的一方（.955 对 .552，见第三节），所以审计要分两步：先给消息打分，再给读者打分。【赌注，2027-04-30 前】接收方一侧的探测器分辨真 cache 和被篡改的 cache，AUROC 超过 .7，并胜过同等成本的文本审计。做不到，状态就跨不出一个所有者的边界。

信誉的前提是卖家可靠与否能被预测。【已证明】在 3.7B 行动前的隐状态上训练一个线性探针，预测它自己会答错，600 道 SQuAD 题上 AUROC .749，好过它自己采样十次的语义熵 .689；127 步 agent 轨迹上第 18 层是 .876。发送方先得知道自己哪里不行，才能给自己的状态标出把握。【赌注，futures 文档预测 11，2027-12-31】接收方做一次后训练，不重新拟合的同族投影器保留率掉 10 分以上；所以信誉得随版本重算。

## 六、回传：一群模型靠什么变强

【赌注，北极星第四句】自我改进的系统不是一个模型变强，而是一群模型互递状态，并从递回来的东西里学。GOAL.md 只说探针（知道自己不行）和通道（把状态交出去）是这个循环的前两步。第三步是让发送方从回传的状态里学，还没做。

【已证明】反向通道是通的（7B→3.7B，6 名字 63.3%）；HotpotQA 拆段上，接收方手里确有发送方没有的东西（文本 45.8 对 30.1）。【赌注，2027-04-30 前】找到一个接收方比发送方高 ≥15 F1 的任务；找不到，这个尺度上的状态交接就没有需求，thesis 讲的是仪器，不是经济。【赌注，2027-10-08 前】三臂实验里，回传状态教给发送方的比等量回传文本多；三个种子上差值 ≤ 0 就算输，"学习"改叫"蒸馏"，thesis 标题去掉 improve。

## 七、反方，以及三种未来里各发表什么

仓库里另一份文件（`docs/agent-communication-futures-2026-09-21.md`）押：法律会把潜在状态留在一家公司的权重之内，跨组织只走可读的文本。【赌注，预测 3，2030-12-31】到期前没有生产系统跨厂商传隐状态。Jev 卖的正是跨边界可读的决策，算它的旁证。

三种未来都有东西可发表。反方赢，这里研究的群体就是一个所有者的模型，仪器、审计和价目表照样成立。通道在 1 MB 这一档死掉，留下的是"文本加探针加审计"，以及一份写明状态何时不值的价目表。赌注全中，我们手上是最早的一套对照组。

## 给造 agent 系统的人：今天就能做的一件事

你不必等通道。任何报告口头置信度基线的论文或评测，把标签本身的 AUROC 印在接收方 AUROC 旁边：先给消息打分，再给读者打分。凡是报告隐状态收益的地方，再加一个错配对照（递另一条样本的状态），否则分不清通道和软提示。两件都不花 GPU，对任何模型家族都适用。
