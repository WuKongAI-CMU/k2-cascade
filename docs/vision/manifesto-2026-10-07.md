# 一个心智能交给另一个心智什么

*宣言，2026-10-07。写给 Peter 和所有在搭 agent 系统的人。每个数字出自 `docs/paper/main.tex`、`docs/thesis/thesis.tex`、`goal/GOAL.md`、`docs/agent-communication-futures-2026-09-21.md`；标【已证明】的是带对照的测量，标【赌注】的是写了日期和失败条件的预测。*

---

两个冻结的、从未一起训练过的模型之间，可以不用一个字就把读过的东西交出去——我们已经量到了这一点，剩下的全是赌注。

计算的单位正在从一个模型变成一群模型：路由、级联、agent 互调。它们之间的协议仍是文本，只因模型碰巧是读文本长大的。这份文件只问一个问题：一个心智能交给另一个心智什么？我们按三层答：先是内容，再是信念的形状，最后是让一群模型越交越强的回传路径。

## 一、内容：读过的东西可以过去

第一批实验用 K2 Horizon 3.7B 和 7B 做发送方和接收方，两个都冻结。发送方读一段文字，它的 KV cache（注意力层算出的键值张量）经一个学出来的逐头映射，塞进接收方的 cache，接收方只看到问题。

绑定测试里（八个生造名字各配一个颜色，只有发送方读过），接收方答对 63.0%，瞎猜 12.5%；给它另一集的 cache，它 63.7% 的概率答出另一集的颜色——它不是在忽略这段 cache，是在读它。【已证明】真实段落上，SQuAD F1 53.0，接收方自己读原文 54.7，只看问题 16.6。【已证明】HotpotQA 把两段证据拆给两个模型，接收方拿到对方段落的 cache 后 F1 从 30.1 升到 39.9±2.1，拿到打乱的 cache 停在 29.9–32.1。【已证明】

一句话：**内容能过线，而且过的是内容，不是"有人在说话"的暗示**——一个用无关文本训练的对照投影器只到 23.4%。

这条线不属于某个模型家族。Qwen3-4B 发给 K2-7B，词表和预训练都不同，绑定测试 71.7±4.5%，和同族相当。【已证明】K2-0.9B 发给 7B 失败了：17.0%，接近乱猜，它的 head 维度、层数、词表三样同时不同，哪一样致命没测。【已证明】闭式线性映射跨家族只有 18.0%，学出来的残差才让它过去。所以几何不匹配是今天这套参数化的边界，不是通道的边界；越过它的路是学出来的消息空间，而不是等所有模型长成一个形状。【赌注，2027-10 前有八对以上模型的目录为证，否则撤回"可迁移性由三元组决定"】

## 二、信念的形状：那个词过去了，读的人没读

一个答案只是一个字符串；发送方在那一刻其实持有一个分布——哪几个备选、各占多少。文本能不能把这个形状交出去？这是 Confidence Laundering（2606.20662）那篇立场论文的主张：文本洗掉了不确定性，需要潜空间载体。

我们量了一件他们没量的事：先给消息本身打分，再给读消息的人打分。附在答案后的"confidence: low"这个词，直接当标签去预测发送方的语义熵，AUROC .955；接收方读完这个词之后的首 token 熵，只有 .552，和没给它任何消息的 .532 一样。【已证明】信号在消息里，读的人把它扔了。这是关于一个基座模型、一个补全提示的事实，不是关于文本的定律——一个被指示过要犹豫的接收方可能抹掉这个差距，我们还没测。

cache 这边：接收方的不确定性跟随发送方的程度，经 cache 是 .585/.605/.624（干净/矛盾/删除三种段落），经原文是 .597/.615/.671。预注册的通过线是 ≥ .70，没到。【已证明】固定问题、只改发送方看到的段落，接收方的熵跟着动：经 cache 相关 .280，经原文 .322，经那个词 .146，经别人的 cache .004。【已证明】

一句话：**cache 带过去的是证据，接收方拿证据重新算了一遍自己的不确定性；发送方的信念形状本身有没有过来，我们还没有一个探针能说。** 两个为此改的训练目标都没动它。下一步是一个独立于接收方决策、专门读发送方候选分布的读出器。【赌注，到 2027-04；若指令微调的接收方读那个词读到 cache 的水平，"不确定性能过线"收缩为"内容过线"】

## 三、回传路径：一群模型靠什么变强

文献里空着的一章。知道自己不行（探针）加把状态交出去（通道）只是前两步；第三步是发送方从返回的东西里学。

前两步有数：3.7B 行动前的隐状态上一个线性探针，预测它自己会答错，AUROC .749，好过它自己采样十次的语义熵 .689；在 127 步 agent 轨迹上 .876。【已证明】反向通道 7B→3.7B 也通，63.3%。【已证明】

第三步的机制是：接收方的答案是一个字符串，它答完后的 cache 里有答案丢掉的东西——权衡过的备选和注意过的证据。发送方若用映射回来的 cache 微调，拿到的不是硬标签。前提是返回的 cache 里得有发送方没有的东西；SQuAD 上没有，HotpotQA 拆段上才有。【赌注：三臂实验，状态回传 − 文本回传在三个种子上 ≤ 0 即杀，届时"学习"改名"蒸馏"，论文标题去掉 improve；2027-10 前出结果】

一句话：**自我改进的系统不是一个模型变强，而是一群模型互相递状态、从递回来的东西里学——这是整个方向里最大、也最没证据的一句。**【赌注】

## 四、账要先算

一个 512 token 前缀的 cache 是 72 MiB，文本约 1 KB。GPU 内投影 24 ms，接收方重读 48 ms；但 1 Gbps 链路上传这 72 MiB 要 604 ms，int4 也要 151 ms。【已证明】层、头都砍不掉：只传后 18 层，SQuAD F1 掉到 16.1。SQuAD 上接收方只比发送方高 3.5 F1，任何触发器都不划算。【已证明】所以今天这条通道是测量仪器，不是部署。让它值这个价钱的两条路：≤ 1 MB 的学出来的编码器保住 F1 在原文 5 分以内【赌注，死条件写在价目表里】；一个发送方和接收方差 15 F1 以上的任务【赌注，三个候选任务先量差距再训练】。

## 五、场上已有的东西

机器人体内，Helix 和 GR00T 已经在层与层之间传状态，不传文本；跨独立模型的还没有。C2C、Interlat、StateBridge、Dense Latent Communication、闭式 KV 映射各自展示了一种跨模型的潜空间接口；一次因果审计（2608.04893）发现 MedQA 上 +14.7 分里只有 +0.4 分是内容，其余是接收方自己多算的。缺的从来不是通道，是对照。另一头，Jev（TypeSafe，2026 年 9 月）是一个只返回带校准概率的类型化决策、不输出文本的模型；"决策不必是字符串"已有人在卖。而对面那份文件《The Wire Splits at the Weights》赌潜空间状态因法律而留在一家公司的权重边界之内，十五条预测在 2027–2030 到期；我们不裁决，只排期：预测 11（接收方更新后投影器掉 10 分以上，2027-12-31）是第一个要跑的漂移测试。

我们能向场上要的只有一行：任何报告口头置信度基线的论文，请把标签本身的 AUROC 印在接收方 AUROC 旁边。
