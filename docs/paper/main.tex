\begin{abstract}
When one language model hands work to another, it writes a message, and everything it computed while reading is left behind. We ask whether a model can hand over its memory instead: the key--value cache it built while reading. Between two frozen models of different size, we learn a map that translates the small model's cache into the large model's, and the large model reads the result as if it were its own. Transplanted memories turn out to be \emph{readable}: the receiver answers questions about text it never saw, at 63\% on a binding test where chance is 12.5\%, and at 53.0 F1 on SQuAD against 54.7 when it reads the passage itself. They are \emph{believed}: handed another item's memory, the receiver answers from it 64\% of the time. They \emph{carry doubt}: when the sender's evidence weakens, the receiver's confidence follows through the memory (Spearman .28) and not through another item's memory (.00), while the words ``confidence: low'' barely move it. And they are \emph{portable, within limits}: the map crosses model families about as well as it works inside one, and fails for a sibling that differs in vocabulary, depth and head size. We release the maps, the tests, and a two-line audit for any handoff between models: score the message, then score the reader.
\end{abstract}

\section{Introduction}
\label{sec:intro}

When one person hands a problem to another, they explain what they know, and the explanation is always smaller than the knowing. The alternatives they weighed, how sure they were, the detail they noticed and did not mention: all of it stays behind. Language models working together do the same thing. A small model reads a document and writes an answer or a summary; a larger model reads that text and carries on. Routers, cascades and multi-agent systems all hand work over in words.

A model is not a person, though. What it remembers about a document is not a feeling. It is a tensor, the key--value (KV) cache its attention layers build while reading, and a tensor can be copied. This paper asks a plain question: \emph{can one language model read another's memory?}

We take two frozen models of different size, K2-Horizon-3.7B and K2-Horizon-7B, and learn a map from the small model's cache to the large model's. The small model reads a passage. The large model never sees the passage; it receives the translated cache in place of its own and answers questions about what is in it. We then ask four things about these transplanted memories, and the answers organise the paper.

\textbf{Readable} (\cref{sec:calib}). The receiver answers from a memory it never formed. Told eight made-up names and their colours only through the cache, it names the right colour 63\% of the time, where chance is 12.5\%. On SQuAD it reaches 53.0 F1, against 54.7 when it reads the passage, and on two-paragraph questions the transplanted memory supplies the paragraph the receiver is missing.

\textbf{Believed} (\cref{sec:believed}). Hand the receiver another item's memory and it answers from that memory 64\% of the time. It is reading, not guessing, and a map trained with nothing to carry cannot do the same. The memory is read in the receiver's later layers: the first half alone carries nothing usable.

\textbf{Carrying doubt} (\cref{sec:survive}). A model's answer is often worth less than how sure it is. When we weaken the sender's evidence, removing the sentence that answers the question, the receiver's confidence moves with the sender's through the memory, and does not move through another item's memory. Through words it barely moves: appending ``confidence: low'' to the sender's answer leaves the receiver tracking the sender about as poorly as with no message at all, although the label itself predicts the sender almost perfectly. The signal is in the message; this reader drops it. The effect through the memory is modest, and we report it with the controls and intervals it needs.

\textbf{Portable, within limits} (\cref{sec:cost}). The same recipe carries a memory from Qwen3-4B into K2-Horizon-7B, across model families, about as well as it works inside one; it fails for a smaller K2 sibling. And memory is heavy: a page of text is 72\,MiB of cache, cheap to hand over inside one machine and expensive across a network.

That memory might move between minds has a long and odd history in neuroscience, down to the transfer of a learned sensitisation between sea slugs by injected RNA \citep{bedecarrats2018rna}. Between language models it is a matter of engineering. What it implies is less ordinary. If the systems we are now building are, in Minsky's phrase, societies of mind \citep{minsky1986society}, the protocol between their members need not be ours. Shannon defined communication as reproducing at one point a message selected at another \citep{shannon1948mathematical}. We ask what is reproduced when the message is a state rather than a string, and find that more crosses than the words would carry.

\section{Transplanting a Memory}
\label{sec:instrument}

\textbf{Models.} The sender is K2-Horizon-3.7B and the receiver K2-Horizon-7B, both frozen and in bf16. They share a tokenizer and the shape of their cache: 36 layers, 8 KV heads, head dimension 128. We record the sender's keys (before rotary position encoding) and values at every layer while it reads, map them, apply the receiver's rotary encoding, and insert the result as the receiver's cache for those positions. The receiver then reads only the question.

\textbf{The map.} It has two parts. First, for each receiver layer and KV head, a ridge regression from the sender's concatenated keys and values (256 dimensions per head) to the receiver's, drawing on the three sender layers whose keys and values correlate best with that receiver layer. Second, a gated residual network on top (bottleneck 128, 151\,M parameters), trained for 1,500 steps on FineWeb-Edu to lower the receiver's loss on the next 512 tokens when it reads the mapped cache of the previous 512. Both language models stay frozen. Nothing in training mentions a question, an answer or a test.

\textbf{Tests.} \emph{Binding}: each episode gives eight made-up names one of eight colours (``Noma is amber. Vela is indigo.\ \ldots''); only the sender reads it, and the receiver is asked the colour of one name. \emph{Passages}: SQuAD v1.1, where the sender reads the passage and the receiver answers the question greedily; we report token-F1. \emph{Doubt}: SQuAD passages in three versions (clean, contradicted, answer sentence removed), described in \cref{sec:survive}. Every test has the same set of arms: the receiver with the question only; the receiver reading the text itself; the receiver's own cache re-inserted (a check on the insertion, which matches reading the text to $10^{-4}$); the sender's cache inserted with no map; the mapped cache; and the mapped cache of a \emph{different} episode, which shares the question and the layout but not the content. That last arm is the one that matters. Where it is given another episode's memory, we also report how often the receiver answers with that episode's value: the \emph{follow rate}.

\section{Transplanted Memories Are Readable}
\label{sec:calib}

\textbf{Facts the receiver never saw.} On the binding test (\cref{tab:main}) the receiver names the right colour 63.0\% of the time from the transplanted memory alone; chance is 12.5\%, and the receiver with only the question gets 10.6\%. The sender's raw cache, inserted with no map, gets 14\%: matching the shape of the cache is not enough. The closed-form ridge map on its own gets 21.7\%. Most of the transfer comes from the learned part, and from letting the linear map move while it learns: on an easier six-name version of the test, freezing the ridge costs about 14 points and feeding each receiver layer from the matching sender layer, rather than the three best-correlated ones, costs about 40 (\cref{app:ablations}). On that version three training seeds give 71.3, 73.0 and 75.3\% (\cref{fig:arms}); with cities and animals in place of colours, 61.8 and 67.2\%; and moving the fact up to 512 tokens away from the question does not lower accuracy (\cref{app:attrs,app:distance}).

\textbf{Real passages.} The binding test is synthetic; SQuAD is not. The map was never trained on questions, yet the receiver answering from the sender's memory of a passage reaches 53.0 F1, against 54.7 when it reads the passage itself and 16.6 with the question alone (\cref{tab:qa,fig:qa}). It recovers almost all of what reading the passage would have given it.

\textbf{The paragraph you are missing.} The cleanest use of another model's memory is when it holds something you do not. On two-paragraph HotpotQA questions we give each model one paragraph. The receiver with its own paragraph scores 30.1 F1; with both paragraphs as text, 45.8; with its own paragraph plus the sender's memory of the other, 39.9 $\pm$ 2.1 over three seeds, recovering about three fifths of the gap. Another item's memory leaves it at 29.9--32.1 (\cref{app:hotpot}).

\section{Transplanted Memories Are Believed}
\label{sec:believed}

A receiver that scores well could still be doing something duller than reading: a learned map can act as a prompt that makes the receiver better at answering in general, and a recent audit of relayed caches found that most of a large gain was of that kind \citep{2608.04893}. Three controls rule this out here.

\textbf{It follows the wrong memory.} Hand the receiver the mapped memory of another episode, with the same names in the same order and a different colour for the one it is asked about, and its accuracy falls to 4.6\%, below chance. In 63.7\% of episodes it answers with the \emph{other} episode's colour (\cref{tab:main}). It is not ignoring the memory and falling back on a guess. It reads the memory and believes it.

\textbf{A map with nothing to carry fails.} We train the identical map with the sender reading text unrelated to what the receiver must predict, so the only thing it can learn is a prompt. It reaches 23.4\% on the binding test, about where the closed-form map alone sits. On SQuAD it scores 15.1 F1, at the level of the question alone. Yet by the usual headline for such maps, how much of the loss gap to reading the text it recovers, it scores 0.77, and 0.72 of that survives when its input is swapped for unrelated text (\cref{tab:retention}). A number that rates a content-free prompt at three quarters of reading the text cannot tell a channel from a prompt; the binding test with its wrong-memory arm can.

A model's answer is often worth less than how sure it is. A cascade that escalates when the small model is unsure, a planner that checks before it acts, a buyer deciding whether to trust a seller: all of them need the sender's doubt, not only its best guess. Text hands over the guess. We ask whether the memory hands over the doubt.

\textbf{Measuring doubt on both sides.} Each SQuAD item comes in three versions: the clean passage; the passage with one inserted sentence asserting a different answer; and the passage with the answer sentence removed. We keep the 377 items the receiver answers correctly from the clean text. The sender's doubt is its semantic entropy \citep{farquhar2024detecting} over ten sampled answers, and it rises as the evidence weakens (0.98, 1.18 and 1.96 on the three versions). The receiver's doubt is its entropy at the first answer token. A handoff carries doubt to the extent that the receiver's entropy predicts whether the sender's is above its median (AUROC). We compare the memory with the receiver reading the passage itself and with three text messages a designer might write instead: the sender's answer plus ``confidence: high / medium / low''; plus a number; and plus every candidate answer with its sampled probability. The confidence word is computed from the sender's \emph{actual} semantic entropy, so the text channel gets an oracle label, the best case for it. Protocol details are in \cref{app:protocol}.

\textbf{Words barely move the reader.} Scored as a label, before any model reads it, the confidence word predicts the sender's doubt almost perfectly: AUROC .955, .942 and 1.000 on the three versions (\cref{tab:confidence}, bottom). That is mostly construction, and it is the point: the signal is in the message. The receiver that reads the message reaches .552, .542 and .592; with no message at all it reaches .532, .479 and .603. A number in place of the word does no better (.548, .532, .563), and neither does the full list of candidates with their probabilities (.495, .489, .626). This base model, under a plain completion prompt, does not turn a written label into its own doubt. The label carries the doubt. The reader drops it.

\textbf{The memory does move it.} Through the transplanted memory the receiver reaches .585, .605 and .624, close to reading the passage itself (.597, .615, .671), and above the confidence word on every version (\cref{fig:audit}, left). The cleanest test holds the question fixed and changes only what the sender read: we remove the answer sentence, the sender's doubt rises, and we ask, item by item, whether the receiver's doubt rises with it. Through the memory the Spearman correlation between the two changes is .280; through the passage, .322; through the confidence word, .146; through another item's memory, which shares the question and differs only in content, .004 (\cref{fig:audit}, right). The receiver's confidence follows what the sender saw, and it follows because of what is in the memory.

\textbf{How large, and how sure.} The effect is modest. Paired bootstrap intervals over passages exclude zero for the memory over the confidence word on the contradicted version ($[.008, .117]$) and not on the other two; reading the passage stays above the memory on the removed version ($[-.091, -.002]$). We had pre-registered a stronger bar for the memory, an AUROC of .70, and it was not met. What the evidence supports is that the evidence crosses and the receiver recomputes its doubt from it, about as well as from the passage and better than from any summary we could write. Whether the sender's own belief crosses as such is a further question.
\label{sec:where}

\textbf{What we could not fix, and where the loss sits.} The sender's own hidden state predicts its doubt better (AUROC .739 on clean passages) than any receiver state does: through the memory .643, through the passage .650 (\cref{app:protocol}). On clean passages the receiver ends up with as much of the sender's doubt through the memory as through the text, and in the shape of the doubt, which alternatives the sender weighed, it is the same: the receiver's mass on the sender's candidates follows the sender's frequencies about as well through the memory (.199) as through the passage (.193), and better than through an explicit list (.166). Two attempts to train the remaining loss away, by making the receiver's distribution through the memory match its distribution through the text or the sender's own entropy, did not move it (\cref{app:negative}).

\section{Portable, Within Limits}
\label{sec:cost}

\begin{figure}[t]
\centering
\includegraphics[width=\columnwidth]{fig_pairs.pdf}

The trained map crosses families (Qwen3-4B) but not a vocabulary and head-dimension change within the family (K2-0.9B).}
\label{fig:pairs}

\textbf{Across families.} A memory is not tied to one family of models. With Qwen3-4B as the sender (a different vocabulary and different pre-training, but the same cache shape as the receiver), we align the two tokenisations by character offsets and train the same map. On the six-name binding test the receiver reads Qwen's memory at 71.7\% $\pm$ 4.5 over three seeds, against 73.2\% within the K2 family, and at 48.3 F1 on SQuAD. The map also runs backwards, from the 7B into the 3.7B (63.3\%). It fails for K2-Horizon-0.9B (17.0\%), a sibling that differs from the receiver in vocabulary, depth and head size at once; which of those differences matters we have not isolated (\cref{fig:pairs}, \cref{app:attrs}).

\textbf{What a memory weighs.} Memory is heavy (\cref{tab:cost}). The mapped cache is 144\,KB per token, 72\,MiB for a 512-token page, against about a kilobyte of text. Inside one machine that is a bargain: on one A100 the map takes 24\,ms where the receiver would take 48\,ms to read the page again. Across a 1\,Gbps link the same memory takes about 604\,ms to send. Four-bit quantisation of the mapped cache costs almost nothing (75.0\% on the six-name test against 75.3, 51.6 F1 against 53.0), so a quarter of the bytes is free; cutting layers is not, even when the missing layers are filled with a structurally valid state instead of zeros (28.7\%, 16.1 F1 for the second half of the network alone; \cref{app:compress}). Today a transplanted memory is worth sending inside a machine and not yet across a network. Teaching a sender to compress what it knows into kilobytes, and keep its doubt, is the problem this paper leaves open.

\section{Related Work}
\label{sec:related}

This paper sits where three old ideas meet. Communication, in Shannon's sense, is the reproduction at one point of a message chosen at another \citep{shannon1948mathematical}; minds, in Minsky's, are societies of smaller agents \citep{minsky1986society}; and a model's uncertainty can be read from its outputs and its hidden states \citep{farquhar2024detecting,kossen2024sep}, although models reading a stated confidence is another matter \citep{tian2023just,yona2024can}. Between language models, messages have long been text; agents have also exchanged embeddings \citep{2310.06272}, hidden states \citep{2511.09149,2608.13317}, and caches, through learned fusers \citep{2510.03215}, closed-form maps within a family \citep{2608.03893} and shared latent spaces \citep{2601.06123,2606.13594}. Audits of these channels showed that much of what looks like communication is extra computation \citep{2608.04893,2607.26773}, and the argument that a handoff in words launders the sender's confidence \citep{2606.20662} set the question we measure. We add the wrong-memory and wrong-sender controls, a within-item test of doubt, and the separation of what a message carries from what its reader takes.

\section{Limitations}
\label{sec:limitations}

The doubt result rests on 377 items of one dataset, one pair of models and one trained map; its effect is a few hundredths of AUROC and is established on one of three passage versions. ``The reader drops the label'' is a property of one base-model receiver under one completion prompt; an instruction-tuned receiver, or one told to hedge, may read the label, and that is the first experiment that could overturn the result. We pre-registered an AUROC of .70 for the memory and did not reach it. The setting is the reuse of a sender's memory of a passage, not the handoff of an agent's reasoning or tool state in the middle of a task. The memory is 72\,MiB per page, and nothing we tried below that size keeps the layers it needs. On SQuAD the larger model is only a few points better than the smaller, so no policy for when to hand off pays there (\cref{app:policy}); the question of when a memory is worth sending needs a task with a larger gap.

\section{Conclusion}
\label{sec:conclusion}

One language model can read another's memory. It reads facts it never saw, it believes what it is given, its confidence follows the sender's evidence where a written ``confidence: low'' does not, and the recipe crosses model families. The memory is still too heavy to send far, and the doubt it carries is still faint. But the systems we are building are societies of models, and their members do not have to talk the way we do. The first thing to measure, for any message between them, is simple: score the message, then score the reader.

\section*{Impact Statement}

This paper presents work whose goal is to advance machine learning. One consequence is specific to it: a receiver that believes whatever memory it is handed (\cref{sec:believed}) can be misled by a forged one. Systems that pass caches between models or devices should authenticate them as they would any other input.

\section{Uncertainty Protocol and Diagnostics}
\label{app:protocol}

\textbf{Uncertainty protocol: items and target.} Following the knowledge-conflict and semantic-entropy protocols \citep{longpre2021entity,xie2023adaptive,farquhar2024detecting}, each SQuAD item gets three passages: \emph{clean}, \emph{contradicted} (one fluent sentence asserting a counter-answer, written by the 375B judge and kept only if DeBERTa-MNLI says it entails the counter-answer and not the gold: 587 of 941 survive), and \emph{removed} (the gold sentence deleted). We keep the 377 items (344 distinct passages) on which the receiver reading the clean passage reaches token-F1 $\ge .5$. The sender's uncertainty is its semantic entropy (SE) over 10 sampled answers (mean 0.98 / 1.18 / 1.96 over the 377 kept items on the three variants, so the sender does notice); the target is SE thresholded at its median per variant. Ten samples make SE coarse: 38 / 40 / 28 distinct values per variant, and on removed passages 22\% of items sit exactly at the threshold. The receiver's uncertainty is its entropy at the first answer token.

\textbf{The four messages.} Two are functions of the passage alone, $M = f(c)$, with the question unseen by the sender: \emph{text} (the receiver reads the passage) and \emph{mapped cache}. Two require the sender to answer the question, $M = f(c, q)$: \emph{verbal} (the sender's greedy answer and ``confidence: high / medium / low'') and its variants with a number (the sender's sample agreement, e.g.\ ``0.8'', the intrinsic-confidence definition of \citet{yona2024can}) or the full candidate list (every answer cluster with its sampled frequency, e.g.\ ``1929 (0.6); 1932 (0.3); 1935 (0.1)''). The four are therefore not one family of messages; the verbal arms have seen the question and the state arms have not, and we compare them anyway because that is the choice a system designer faces. The confidence word is an oracle label built from the sender's \emph{actual} SE terciles, favourable to the text channel; the sender does not verbalise its own confidence. The terciles are taken over all 587 items per variant and the target median over the 377 kept items, which is why the label's own AUROC is below 1 on two variants (\cref{app:where}). The receiver's prompt is a plain completion---``A smaller model that read the passage answered: \emph{X} (confidence: \emph{high}).'' followed by the question---with no chat template, no few-shot examples and no instruction to hedge; we did not ablate it, and \cref{sec:limitations} says what that leaves open.

\textbf{Controls and metrics.} Content-free controls: a \emph{deranged cache} (another item's mapped cache), a \emph{zero cache}, a \emph{moment-matched random cache}, and \emph{question only}. Each handoff is scored at two levels against the same target $u_S$ (sender SE above its median): the \emph{message-level signal}, the AUROC of a fixed function of the message alone (a confidence word's rank; for the cache, a linear probe on the mapped message), and the \emph{receiver-level signal}, the AUROC of the receiver's first-token entropy after reading it. Their difference is the read-out gap: a difference of two AUROCs, not an information decomposition, and the cache's two levels use different instruments, so the gap is comparable within an arm, not across arms. The drop ratio is a handoff's decrease in the receiver's $P(\text{gold})$ from clean to removed divided by the text path's decrease; it is a relative drop in confidence, not a fraction of uncertainty information retained, and the paths start from different confidence levels. Values are in \cref{tab:confidence}.

\begin{tcolorbox}[breakable, enhanced, colback=white, colframe=black, boxrule=0.5pt, arc=0pt, left=3pt, right=3pt, top=2pt, bottom=2pt, before skip=4pt, after skip=6pt]
\small
\textbf{Capacity, stated correctly.}
A message that is the argmax of the sender's belief $p_S$ plus a $k$-level label takes at most $|Y|\,k$ values, so it carries at most $\log |Y| + \log k$ nats about $p_S$; a state message is not so bounded, although what the receiver recovers from it is bounded by the map and by its reading. This limits information about the \emph{distribution} $p_S$ (which alternatives, how spread), not a detector's AUROC against a thresholded target: a three-level label reaches AUROC .955 against the median split (\cref{app:where}). An earlier draft of this paper deduced a lower receiver-level AUROC for the text arm from this ``$\log 3$ nats'' bound; that deduction was wrong and is withdrawn. The bound is not what limits the text arm here, and no measurement in this paper tests it.
\emph{Why recovering the belief would matter.} If the receiver's recovered belief $\tilde b$ is within total variation $\varepsilon$ of the sender's $b$ and one-step rewards lie in $[0, R_{\max}]$, then acting on $\tilde b$ instead of $b$ loses at most $2 R_{\max} \varepsilon$ in expected reward. That is what a decision test should measure; this paper measures the read-out gap and the tracking of $u_S$, not regret.
\end{tcolorbox}


\textbf{Controls, per variant.} The content-free controls do not sit at one level. On clean and contradicted passages they lie at .46--.54 (question only .532 / .479; deranged .536 / .488; random .457 / .472; zero .496 / .481) against the cache's .585 / .605. On removed passages question-only alone gives .603, the random cache .580 and the deranged cache .564 against the cache's .624: the question already carries most of the signal when the answer is gone, and question-only there beats the word (.592). The cache's increment over question-only is therefore $+.053$ on clean, $+.126$ on contradicted and $+.021$ on removed passages, and only the middle one is established.

\textbf{Behaviour under contradiction and removal.} When the answer is removed, the cache path loses 54\% of the confidence the text path loses and its entropy rises by 73\% of the text path's rise. Under a contradiction the text path is swayed slightly more by the inserted sentence than by the original ($P(\text{counter})$ .32 $>$ $P(\text{gold})$ .29), while the cache path keeps the original ahead (.25 $>$ .22); across all conditions the cache path is less confident than the text path on clean passages ($P(\text{gold})$ .28 vs .44), so a receiver that treats the two channels as equivalent would under-trust the cache (\cref{fig:confidence}). What this section cannot say is why the ordering is what it is; that is the next section's job.


\subsection{Where the loss occurs}
\label{app:where}

\textbf{(a) The label carries the signal; this receiver does not read it.} The confidence word is built from the sender's own SE terciles, so scored as a label it predicts the binary target almost perfectly without any receiver: AUROC .955 / .942 / 1.000 on the three variants, the numeric label .870 / .848 / .735 (\cref{tab:confidence}, bottom). These numbers are a property of the construction---a tercile split over all 587 items against a median split over the 377 kept items---and the 1.000 on removed passages is a degeneracy: 22\% of items tie at the threshold and the tercile boundary coincides with it. The audit is a sanity check, not a finding; the finding is the other bar: the receiver's first-token entropy after reading that word reaches .552 / .542 / .592. The text channel is not capacity-limited here; this base-model receiver, under one completion prompt, does not turn a label into its own spread. That is a statement about one reader and one prompt format; a receiver instructed to hedge, given few-shot examples, or instruction-tuned could erase the contrast, and we did not test one. It is also why the capacity argument of our earlier draft (the box above) cannot be the mechanism of the verbal arm's shortfall.

\textbf{(b) Within-item intervention.} Cross-item correlations admit a common cause: a hard question makes both models uncertain whether or not anything crosses. The variants allow a paired test with the question held fixed and only the sender's passage changed (clean $\rightarrow$ removed; the sender's SE rises by 0.98 on average). Per item, the Spearman correlation between the receiver's entropy change and the sender's SE change is .280 through the mapped cache, .322 when the receiver reads the text, .146 through the confidence word, and .004 through a cache from another item, which shares the question and rules out the common cause (\cref{fig:audit}, right). The same-sign rates (88 / 90 / 49 / 47\%) are weaker evidence than they look: the sender's SE rises on 91.5\% of items, so any arm whose entropy simply rises on removal scores near that ceiling and an arm with no mean shift sits at a coin flip; same-sign measures the mean shift, the Spearman the per-item covariation. Under a contradiction the effect is smaller (cache .208, text .325, word .179, deranged .004). The receiver's confidence moves with what the sender saw, and it moves because of the cache's content. It licenses no more than that: the text path tracks at least as well, so the parsimonious reading is that the evidence crosses and the receiver recomputes its own uncertainty from it.

\textbf{(c) Shape of the belief.} Sender SE and receiver first-token entropy are different measurements; a diagnostic closer to the belief itself is the \emph{shape}: per item with at least two sampled answer clusters, the Spearman correlation between the sender's cluster frequencies and the receiver's first-token mass on those candidates. On clean passages ($n = 323$) it is .199 through the mapped cache, .193 from the text, .166 from the explicit candidate list, and .052 / .042 for the deranged cache and question only: there the receiver recovers the sender's alternatives about as well from the cache as from the passage, and no better from a list of them. Under a contradiction ($n = 351$) the order reverses (cache .153, list .201, text .234), and on removed passages every arm is near zero. No interval was computed for these correlations, and they are small enough that the diagnostic separates arms from the controls, not from each other.

\textbf{(d) Four-point probes.} The same standardised logistic probe ($C = 0.05$, five passage-grouped folds, no inner selection; the semantic-entropy-probe protocol of \citealp{kossen2024sep}) for the binary sender-SE target at four points of the chain, on inputs of 2560 / 2048 / 6144 / 4096 dimensions and on the 587 items (the full set before the F1 filter, so these AUROCs are not directly comparable with \cref{tab:confidence}). Clean / removed: the sender's own last-prompt-token state, averaged over layers 12 / 18 / 24, gives .739 / .706; the mapped message at its last prefix position, averaged over layers and heads, .557 / .579 (with the question-only receiver state concatenated, .563 / .603); the receiver's state after reading through the mapped cache .643 / .563; after reading the text .650 / .654; the question alone .530 / .591. Three things follow. The sender holds more about its own uncertainty than any receiver state recovers. On clean passages the receiver reaches .643 through the cache, above the .557 that the probed message carries, so the message carries more than a one-position probe reads, and the cache leaves the receiver with as much as the text does (.643 vs .650); on removed passages the receiver (.563) falls below the probed message with the question (.603) and below the text (.654). These probes therefore do not localise the loss. Two caveats bound them further. The message-level probe sees one position of 512, so .557 / .579 bounds what one position carries, not what the map preserves; a pooled read-out of the whole prefix is the obvious next probe. And the sender probe saw the question as well as the passage, while the mapped message is passage-only, so sender-minus-message mixes question conditioning with map loss.

\section{When Should the Small Model Hand Off?}

On 600 SQuAD items the 3.7B alone reaches F1 52.2 and gets 35.5\% of items wrong (F1 $< 0.5$). A logistic probe on its pre-action hidden state (last prompt token, layers 12/18/24; the probe of \citealp{kossen2024sep} with a failure label; five-fold, not grouped by passage, $C = 0.1$) predicts those failures with AUROC .749, better than its own semantic entropy (.689), sample disagreement (.683), max-probability (.582) or entropy (.584) (\cref{tab:policy}). But the 7B reading the passage reaches only 55.7, the mapped cache 51.8 and the verbal handoff 47.0, so no trigger makes a handoff pay at equal latency (\cref{fig:policy}): the probe-triggered text handoff climbs from 52.2 to 55.7 as the handoff rate goes to 1, the cache handoff stays flat at 52, and only an oracle trigger gains (56.4 at rate .4). On this task the receiver is not enough better than the sender for a handoff of any kind to be worth it; the probe result stands, the policy result waits for a task with a real gap.
